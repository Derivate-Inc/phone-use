# Phone Use site

The landing page and public documentation are one Next.js application.

## Local development

```bash
bun dev
```

Open:

- Landing page: [http://localhost:3000](http://localhost:3000)
- Documentation: [http://localhost:3000/docs](http://localhost:3000/docs)

Documentation content and navigation live under `app/docs/`. Run `bun run build`
before shipping changes.

## Production build

```bash
bun run build
```
